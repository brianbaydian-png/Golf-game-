# Pinecrest Links

A 9-hole top-down golf game in a single HTML file. Open `index.html` in a browser to play.

- Full bag: Driver, 3W, 5W, 4–9 irons, PW, SW, LW, putter (with caddie club suggestions)
- Three-tap swing meter: start, set power, then time the accuracy snap (early slices, late hooks)
- Wind, fairway/rough/bunker lies, water hazards, trees, out of bounds
- Zoomed putting view with sloped greens and lip-outs
- Scorecard with best-round tracking

Controls: tap/drag on the course to aim, `Space` to swing, `←`/`→` to fine-aim, `↑`/`↓` to change club.
